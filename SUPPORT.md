# TinyAtom Support

TinyAtom 0.1 supports Apple silicon Macs running macOS 13 or later. Intel Macs and Windows are not part of this release.

For a product problem, open a [TinyAtom support issue](https://github.com/org-tinyatom/tinyatom-downloads/issues). GitHub sign-in may be required. Include:

- what you expected and what happened;
- steps that reproduce the problem;
- the TinyAtom version and macOS version;
- whether the problem concerns TinyAtom, an atom, a runtime, or a coding agent;
- the redacted report from **Settings → About → Copy diagnostics**.

Use **Settings → About → Open logs** when logs are requested. Inspect them before sharing. Do not post tokens, private keys, credentials, private repository names, confidential atom source, user documents, or personal data.

For a suspected vulnerability, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.
