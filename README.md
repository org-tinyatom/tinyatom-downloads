# TinyAtom Downloads

This public repository hosts verified release artifacts for TinyAtom and its managed runtimes. TinyAtom's application source remains in its private development repository.

Use [GitHub Releases](https://github.com/org-tinyatom/tinyatom-downloads/releases) for downloads. Every application release includes `SHA256SUMS.txt`; runtime releases include their descriptor, provenance, license, notarization, and clean-Mac evidence.

TinyAtom 0.1 supports Apple silicon Macs running macOS 13 or later. Intel Macs and Windows are not part of this release.
